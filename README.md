##Результаты замера Debug vs Release 
| Режим   | Запуск 1 | Запуск 2 | Запуск 3 | Запуск 4 | Запуск 5 | Минимум | 
| ------- | -------: | -------: | -------: | -------: | -------: | ------: | 
| Debug   |     1886 |     1890 |     1885 |     1888 |     1887 |    1885 | 
| Release |      620 |      615 |      618 |      622 |      619 |     615 |      
В моём эксперименте Release оказался быстрее Debug
Когда я открыл в ILSpy сначала Debug-сборку, а потом Release, разница была видна сразу:
В Debug есть куча инструкций nop — это пустые операции, которые ничего не делают. В Release их нет вообще.
В Release пропали лишние операции с локальными переменными: в Debug результат сначала сохраняется в переменную (stloc), а потом читается обратно (ldloc). В Release этого нет, значение сразу идёт на возврат.
Release-код выглядит чище и короче.
